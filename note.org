** 右手中微子能谱
右手中微子（RHN）由太阳中微子（SN）混合产生，其通量[fn:1]：
\[\Phi(E_{\nu_{H}}) = |U_{eH}|^2 \sqrt{1 - (\frac{m_{\nu_H}}{E_{\nu_H}})}\Phi_{^8 \mathrm{B}}(E_{\nu})\]

#+attr_latex: :width 0.5\textwidth

** 右手中微子寿命与分支比
衰变宽度与寿命：
\begin{align*}
\Gamma^{\mathrm{total}}_{\mathrm{c.m.}} &= \Gamma^{\nu\nu\nu}_{\mathrm{c.m.}} + \Gamma^{\nu ll}_{\mathrm{c.m.}}\\
&=\frac{G_F^2}{192\pi^3}m^5_{\nu_H}|U_{eH}|^2\left[1 + h\left(\frac{m_e^2}{m_{\nu_H}^2}\right)\right]\\
\tau_{\mathrm{c.m.}} &= 1 / \Gamma^{\mathrm{total}}_{\mathrm{c.m.}} 
\end{align*}
这里 \(\nu\nu\nu\) 和 \(\nu ll\) 是右手中微子衰变的两个分支。对于 MeV 量级的太阳中微子，只存在 \(3\nu_{e}\) 和 \(\nu_{e} e^{+}e^{-}\) 两种衰变模式[fn:2]。

** 右手中微子衰变截面
衰变截面：
\[\frac{\mathrm{d}\Gamma_{\mathrm{c.m.}}}{\mathrm{d}E\mathrm{d}\cos\theta} = \Gamma^{\mathrm{total}}_{{\mathrm{c.m.}}}(f_{1}+\xi|\vec{P}|f_{S}\cos\theta),\]
其中 \(E\) 和 \(\theta\) 是 \(\nu_e\) 在质心系中的能量和散射角，\(f_1\) 和 \(f_S\) 是关于 \(m_{\nu_H}\) 和 \(E\) 的函数，\(|\vec{P}|\approx\beta\) 表示 \(\nu_H\) 的偏振率。对于 \(\nu_{H}(\bar{\nu}_{H})\), \(\xi = +1(-1)\).

衰变后正负电子夹角[fn:3]：
\[\cos\alpha = \frac{2m_{e}^{2}+E_{e^{+}}E_{e^{-}}-m_{\nu_{H}}^{2}-2E_{H}E_{\nu}-2\sqrt{E_{H}^{2}-m_{H}^{2}}\cos\theta}{p_{e^{+}}p_{e^{-}}}\]

** 中微子与电子散射截面
对一个初始能量为 \(q\) 的中微子，产生能量为 \(T\) 的反冲电子的散射截面：
\[\frac{\mathrm{d}\sigma}{\mathrm{d}T} = \sigma_e [g^2_L + g^2_R(1-T/q)^2 - g_L g_R (T/q^2)],\]
其中
\begin{align*}
g_L &= (\pm 1/2 + \sin^2 \theta_W),\quad g_R = \sin^2 \theta_W \approx 0.23\\
\sigma_e &= 2G_F^2 m_e^2 / \pi\hbar^4 = \qty{88.083e-46}{cm^2}
\end{align*}

** COMMENT 右手中微子衰变夹角
使用 MadGraph 模拟 RHN 衰变电子夹角:
#+begin_src text
  import model SM_HeavyN_Dirac_LO
  generate e+ e- > n1 ve~
  output HNL
  launch HNL
#+end_src
- 通过设置 =ebeam= 能量限制 RHN 能量
- 通过设置 =madspin_card.dat= 限定 \(\nu_{H}\rightarrow\nu_{e}e^{+}e^{-}\) 衰变
  #+begin_src text
  set spinmode onshell
  decay n1 > ve e+ e-
  launch
  #+end_src

** 右手中微子衰变电子夹角
使用 MadGraph 模拟 RHN 衰变电子夹角。先产生静止 RHN 衰变事例：
#+begin_src text
  import model SM_HeavyN_Dirac_LO
  generate n1 > e+ e- ve~
  output HNL
#+end_src

然后调整
- =param_card.dat=: 设置 ~mN1~ 和 ~VeN1~.
- =run_card.dat=: 设置 ~nevents~, 将 ~ebeam~ 相关置 0.

最后对产生的事例，通过 RHN 能谱抽样，赋予对应质心系动量并 boost 到对应实验室系。

后续结果均针对 \(m_{\nu_{H}} =\qty{10}{MeV}, |U_{eH}|^{2} = 10^{-5}\) 情形。
